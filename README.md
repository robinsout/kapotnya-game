# Капотня

Небольшая пиксельная браузерная игра. Ночь, Капотня, нефтеперерабатывающий завод — и на него летят дроны.
Катайся на зенитке вдоль завода, сбивай дроны, подбирай сброшенные на парашютах ящики с патронами
и ракетами. Если дроны разнесут завод — взорвётся большая цистерна, и её крышка улетит в небо.

## Управление

| Действие              | Клавиши                         |
| --------------------- | ------------------------------- |
| Ехать                 | `A` / `D` или `←` / `→`         |
| Целиться              | мышь                            |
| Огонь                 | ЛКМ (зажать) или `F`            |
| Ракета (самонаводка)  | ПКМ, `Пробел`, `W` или `↑`      |
| Старт / заново        | `Enter`, `Пробел` или клик      |
| Пауза                 | `P` / `Esc`                     |
| Звук                  | `M`                             |

### На телефоне

- Касание неба — прицел и огонь (держи палец, чтобы стрелять очередью).
- Кнопки ◀ ▶ — ехать, «РАКЕТА» — пуск. Мультитач: можно ехать и стрелять одновременно.
- ❚❚ — пауза, ♪ — звук, ⛶ — полный экран (на Android ещё и фиксирует альбомную ориентацию).
- В альбомной ориентации кнопки уходят в боковые поля, в портретной — вниз, под большие пальцы.
- Игра сама встаёт на паузу, если свернуть браузер или заблокировать экран.

**Правила.** Патроны и ракеты — конечный ресурс: сами они не восстанавливаются.
Пополнить их можно только ящиками, которые падают из сбитых дронов, — иначе они кончатся.
Патронов мало, ракет максимум три. Когда патронов почти нет, HUD предупреждает,
а ящики с патронами выпадают чаще — но их всё равно надо успеть поймать. Квадрокоптер сбивается одним попаданием,
дельтаплан-камикадзе — тремя. Ракета взрывается по площади и сносит всё рядом.
Ящики подбираются, когда зенитка проезжает под ними; на земле они лежат несколько секунд.
Со временем дронов становится больше, а камикадзе — чаще.

## Разработка

```bash
npm install
npm run dev        # dev-сервер Vite
npm test           # unit-тесты (Vitest)
npm run typecheck
npm run build      # сборка в dist/
```

В dev-режиме объект приложения доступен в консоли как `window.kapotnya`.

### Архитектура

Игровая логика — чистый TypeScript без DOM; рендер, ввод, звук и UI — тонкие адаптеры вокруг неё.

```
src/
  config.ts           все игровые константы (баланс)
  core/               математика, геометрия, seeded RNG, фиксированный шаг
  game/               доменная модель
    types.ts, state.ts  состояние игры
    refinery.ts         раскладка завода (общая для логики и рендера)
    step.ts             один шаг симуляции: фазы title → playing → collapse → over
    systems/            turret, drones, projectiles, pickups, spawner, collapse, particles…
  render/             пиксельный рендер на canvas 320×180 (спрайты из ASCII-арта)
  input/              клавиатура/мышь/тач → InputState
  audio/              синтез звуков через WebAudio (без ассетов)
  ui/                 HUD и экраны в DOM, раскладка под экран/тач, рекорд в localStorage
  app.ts              игровой цикл; зависит только от портов (интерфейсов), тестируется с фейками
  main.ts             сборка зависимостей (composition root)
tests/                зеркалит src/
```

Системы получают `Rng` параметром, поэтому вся логика детерминированно тестируется.
События шага (`state.events`) — единственный канал из симуляции в звук и UI.

### Деплой

Workflow `.github/workflows/ci.yml` прогоняет проверки на каждый push, а с основной ветки (`master`)
публикует `dist/` на GitHub Pages (`configure-pages` пытается включить Pages сам; если не вышло —
в настройках репозитория: Pages → Source → GitHub Actions).
